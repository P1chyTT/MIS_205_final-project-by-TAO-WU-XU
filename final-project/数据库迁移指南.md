# 数据库迁移指南

## 问题说明

你遇到了以下错误：
1. `Could not find the 'contact_info' column of 'posts' in the schema cache` - 联系方式字段不存在
2. `Could not find the table 'public.trip_expenses' in the schema cache` - 行程费用表不存在

这是因为新功能需要更新数据库结构，但迁移脚本还没有在Supabase中运行。

## 解决方案

### 方法1：运行完整schema.sql（推荐）

1. 登录到你的Supabase项目
2. 进入 **SQL Editor**
3. 复制 `final-project/schema.sql` 的全部内容
4. 点击 **Run** 执行

这个脚本会：
- 创建所有必要的表
- 添加所有必要的列
- 设置RLS策略
- 创建索引和触发器

### 方法2：运行单独的迁移脚本

如果你只想添加新功能，可以运行：

#### 步骤1：运行图片相关迁移
```sql
-- 在 Supabase SQL Editor 中运行
ALTER TABLE posts 
ADD COLUMN IF NOT EXISTS image_url TEXT,
ADD COLUMN IF NOT EXISTS image_urls TEXT[] DEFAULT '{}';
```

#### 步骤2：运行费用和联系方式迁移
运行 `final-project/migration_add_expenses_contact.sql` 中的全部内容。

### 方法3：手动添加缺失的字段

如果只想修复当前问题，可以运行以下SQL：

```sql
-- 添加联系方式字段
ALTER TABLE posts 
ADD COLUMN IF NOT EXISTS contact_type VARCHAR(10),
ADD COLUMN IF NOT EXISTS contact_info VARCHAR(100);

-- 创建行程费用表
CREATE TABLE IF NOT EXISTS trip_expenses (
    id          SERIAL PRIMARY KEY,
    post_id     INT NOT NULL REFERENCES posts(id) ON DELETE CASCADE,
    name        VARCHAR(100) NOT NULL,
    amount      DECIMAL(10,2) NOT NULL,
    note        TEXT,
    created_at  TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- 创建索引
CREATE INDEX IF NOT EXISTS idx_trip_expenses_post_id ON trip_expenses(post_id);

-- 启用RLS
ALTER TABLE trip_expenses ENABLE ROW LEVEL SECURITY;

-- RLS策略：所有参与者都可以管理费用
CREATE POLICY "参与者可管理费用" ON trip_expenses
    FOR ALL USING (
        EXISTS (
            SELECT 1 FROM participations p
            WHERE p.post_id = trip_expenses.post_id 
            AND p.user_id = auth.uid()
        )
        OR
        EXISTS (
            SELECT 1 FROM posts 
            WHERE posts.id = trip_expenses.post_id 
            AND posts.user_id = auth.uid()
        )
    );
```

## 验证迁移是否成功

运行以下SQL检查：

```sql
-- 检查联系方式字段
SELECT 
    column_name,
    data_type,
    is_nullable
FROM information_schema.columns 
WHERE table_name = 'posts'
AND column_name IN ('contact_type', 'contact_info', 'image_url', 'image_urls');

-- 检查费用表
SELECT 
    table_name,
    column_name,
    data_type
FROM information_schema.columns 
WHERE table_name = 'trip_expenses';
```
